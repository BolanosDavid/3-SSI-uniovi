Sistema informático es seguro cuando:
	Responde según lo previsto
	Evita que los usuario realicen operaciones no autorizadas
	Garantiza CIA: Confidencialidad, Integridad y Disponibilidad
Objetivos de la seguridad informática:
	Identificar vulnerabilidades
	Crear y configurar contramedidas contra ellas
	Evitar las amenazas existentes que explotan estas vulnerabilidades
Metadatos:
	Datos que proporcionan información sobre otros datos(por ejemplo, en las fotos aparece la ubicación donde se hizo la foto, el autor, fecha...)
Terminología básica:
	Amenaza: algo que _podría causar daño_ (una persona, un malware, un fallo eléctrico, una inundación, etc.). Ejemplo: un atacante intentando entrar en tu cuenta.
	Vulnerabilidad: una _debilidad_ en un sistema que permite que algo salga mal. Ejemplo: una versión vieja de un software con un fallo conocido.
	Exploit: la _forma concreta de aprovechar_ una vulnerabilidad (técnica, código o procedimiento). Ejemplo: un script que usa ese fallo para ejecutar comandos.
	Payload (carga útil): lo que “va dentro” del exploit: _la acción final_ que se quiere conseguir una vez se entra. Ejemplo: robar datos, crear un usuario admin, instalar un ransomware, abrir una puerta trasera.
		Amenaza = quién/qué puede atacar
		Vulnerabilidad = por dónde entra
		Exploit = cómo entra
		Payload = qué hace al entrar
